# The full report

The report is EnergCalc's paid product. It appears **on screen in the portal** and can be **downloaded as a PDF** — both versions are built from the same data model, so they never disagree.

## Why it can be trusted

**It is calculated on the server.** The on-screen preview uses the engine in the browser, but the paid report uses an **official calculation** run on the server, with the up-to-date catalog, and stored as an **immutable snapshot**. Nobody can edit the result afterwards.

**It is traceable.** Every report records the engine version, the regional rules version and the catalog version it used.

**It keeps things separate.** The report clearly distinguishes:

1. automated preliminary planning;
2. manufacturer-documented specifications;
3. identified certification documents;
4. compatibility calculated by the engine;
5. professional review.

**It doesn't overstate.** The budget separates **products**, **installation** (a separate estimate), **shipping** and **taxes**, and shows the source and date of every price. Items without a price show "no price on file".

## What the report is not

The report is **not an engineered design** and carries **no professional certification** (in Brazil, an ART). Until a region's installation rules are reviewed by a licensed professional, the report contains no assembly instructions. Instead, it lists what to bring to the electrician and the questions they should answer.

## Delivery

- **On screen:** clickable table of contents, tables, formulas and diagram.
- **As a PDF:** generated on the server and delivered through a temporary link, only to you.
