# Estação pronta × sistema montado

O EnergCalc compara sempre as duas abordagens. Nenhuma é "melhor" em todos os casos.

| | Estação de energia pronta | Sistema montado |
|---|---|---|
| **O que é** | Bateria, inversor e carregador numa caixa só | Baterias, inversor, controlador, cabos e proteções separados |
| **Instalação** | Nenhuma: tirou da caixa, usou | Exige profissional habilitado |
| **Portabilidade** | Alta | Baixa (instalação fixa) |
| **Custo por kWh** | Maior | Menor em sistemas grandes |
| **Expansão** | Limitada ao que o fabricante oferece | Ampla, dentro dos limites dos componentes |
| **Faixa ideal** | Até ~2–3 kWh | Vários dias de autonomia, com solar |

## Como a recomendação é escolhida

- Se você pediu **estação pronta** ou **portabilidade**, a estação é recomendada quando atende.
- Se pediu **sistema montado** ou **solar**, recomenda-se a configuração equilibrada.
- No modo **"não sei"**, a estação é recomendada quando tem custo competitivo; caso contrário, o sistema montado.
- Se nenhuma estação do catálogo cobre toda a autonomia, aparece a **mais próxima**, com as horas que ela sustenta.

> **Independência comercial.** Links de indicação (afiliados) nunca alteram o resultado técnico nem a ordem das recomendações. Sempre que um link de indicação aparece, ele vem identificado como tal.

## O catálogo

O catálogo começa pequeno e documentado: estações de energia de marcas conhecidas, baterias, inversores, painéis, controladores MPPT e proteções (fusíveis, cabos, seccionadores, chave de transferência).

Cada produto tem um **status de verificação**:

| Status | Significado |
|---|---|
| Não verificado | Dado incompleto ou ainda não confirmado no documento oficial. |
| Documentado pelo fabricante | Especificação apoiada por página ou datasheet oficial. |
| Conformidade documentada | Documento de certificação identificado (por país). |
| Verificado | Especificações e documentos revisados. |
| Descontinuado / Recall / Rejeitado | Fora das recomendações. |

**Regras do catálogo:**

- **Especificação ausente fica ausente.** Um pico de partida não informado pelo fabricante aparece como dado insuficiente — e essa estação não é recomendada para cargas com motor.
- **Preço só com fonte e data.** Um item sem cotação aparece como "preço não cadastrado", em vez de um valor estimado.
- **Certificações não são intercambiáveis.** Inmetro, UL e CE valem cada uma para seu país.
- **Componentes genéricos** (bateria, inversor, painel de referência) são marcados como tal, para mostrar especificações típicas de mercado.
